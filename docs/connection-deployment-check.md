## Notion 운영 오류

새 테스트 회원 ID `1722492`로 운영 서버에서 재현했습니다.

- Vercel 프로젝트 `moeum`의 API 주소는 `https://fastapi-practice-jwse.onrender.com`으로 정상입니다.
- 운영 CORS는 `https://moeum-log.vercel.app`의 Authorization 요청을 허용했습니다.
- 서버가 발급한 Notion 승인 URL의 콜백이 `http://localhost:5173/auth/notion/callback`이었습니다.
- Render의 `NOTION_OAUTH_REDIRECT_URI`를 `https://moeum-log.vercel.app/auth/notion/callback`으로 변경하고 재배포했습니다.
- Notion 개발자 설정의 MOEUM OAuth 앱에도 운영 콜백을 추가했습니다. 기존 로컬 콜백은 유지했습니다.
- 이후 운영 사이트에서 Notion 페이지 선택 화면까지 정상 진입했습니다.
- 최종 페이지 접근 승인, 실제 토큰 교환 및 사용자의 Notion 페이지 수집은 미검증입니다. 브라우저 제어가 현재 URL을 확인하지 못해 중단됐습니다.

사용자별 암호화된 토큰, 단일 사용·10분 만료 state, 프로젝트 소유자/명시적 멤버 접근 검사를 유지합니다. 연결되지 않은 새 회원에게 다른 사용자의 서버 토큰을 제공하지 않는 것을 확인했습니다. 백엔드에는 콜백 경로·허용 origin·Render HTTPS 검사와 인증 만료/페이지 권한별 오류 안내를 추가했습니다.

## Figma OAuth와 GitHub

- 운영 Figma OAuth 앱 ID `F3cNFpUpsDi9W623ZzU5w4`가 사용자에게 표시된 존재하지 않는 앱 ID와 일치합니다. 유효한 앱의 Client ID/Secret 재설정은 미완료입니다. 실시간 플러그인은 이 앱을 사용하지 않습니다.
- GitHub 저장 기록이 비어 있으면 화면 진입 때마다 전체 브랜치를 수집하던 자동 호출을 제거했습니다. 최초 수집도 사용자가 새로고침으로 시작합니다.

- 대기 상태는 서버 프로세스 메모리에 보관하므로 재시작하면 초기화됩니다. 현재 서비스는 인스턴스 1개이며, 여러 인스턴스로 늘리려면 공유 저장소가 필요합니다.
